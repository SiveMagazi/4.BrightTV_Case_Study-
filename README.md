## BrightTV Viewership Analytics Case Study
# Project Overview

This project forms part of a Data Analytics course and focuses on analysing BrightTV's viewership data to understand customer behaviour and content consumption patterns. The primary objective is to support the Customer Value Management (CVM) team by providing actionable insights that can help BrightTV grow its subscription base and increase viewer engagement.

As a Data Analyst, the project requires investigating how BrightTV viewers behave, how they consume BrightTV channels and content, and which factors influence usage trends. The analysis aims to uncover meaningful insights that can support data-driven business decisions and customer growth strategies.

# Business Problem

BrightTV's CEO has set a strategic objective to increase the company's subscription base during the current financial year. To support this objective, the analysis seeks to identify trends, consumption patterns, and opportunities that can help improve customer acquisition, retention, and engagement.

## Project Objectives

The analysis addresses the following key business questions:

Identify user and viewership trends across the BrightTV platform.
Understand viewer consumption behaviour and engagement patterns.
Determine the factors that influence content consumption.
Recommend content strategies for periods with lower viewership.
Propose initiatives that can contribute to subscriber growth.
Translate data insights into actionable business recommendations.
Dataset Description

## The dataset contains:

Customer profile information.
Viewer transaction and session-level consumption data.
User activity records that capture viewing behaviour.
Important Notes
All timestamps are provided in UTC and must be converted to South African Standard Time (SAST).
Consumption data is recorded at session level, meaning each viewing session is represented as a separate record.
Additional supporting data may be incorporated where relevant to strengthen the analysis.

## Data Analytics Process

1. Data Understanding
Review dataset structure and available fields.
Understand business objectives and analytical requirements.
Identify key metrics related to viewership and engagement.
2. Data Cleaning and Preparation
Handle missing and inconsistent values.
Convert UTC timestamps to South African Standard Time.
Remove duplicates where necessary.
Create derived features to support analysis.
3. Exploratory Data Analysis (EDA)
Analyse customer demographics and viewing activity.
Identify peak and low consumption periods.
Explore behavioural patterns across users and sessions.
Examine content preferences and viewing trends.
4. Insight Generation
Identify drivers of viewer engagement.
Detect behavioural patterns influencing consumption.
Discover opportunities for increasing platform usage.
5. Business Recommendations
Recommend content scheduling strategies.
Suggest customer retention and acquisition initiatives.
Propose actions to improve engagement during low-consumption periods.
